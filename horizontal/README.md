# MusicRoad Drive 1.0

Interface horizontal dedicada a centrais multimídia automotivas.

- abre automaticamente em landscape no APK
- mapa, rota, instruções e alertas integrados
- música e rádio em segundo plano
- Drive Assist com radares e quebra-molas
- mapas offline armazenados no dispositivo
- usa o mesmo login, banco, planos e configurações da versão vertical

O APK público é MusicRoad 1.2.0 (versionCode 26). O DriveOS e a interface vertical compartilham o mesmo serviço Android de navegação e a mesma assinatura de produção.
