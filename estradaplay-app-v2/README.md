# EstradaPlay 2.0.0

Código-fonte Android consolidado. Esta pasta é a fonte definitiva da série 2.x.
O build deve compilar diretamente `estradaplay-app-v2/`; não aplicar scripts 1.5–1.7.

Inclui:
- horizontal + vertical nativos;
- controles compatíveis com touchscreen/mouse/stylus/ENTER automotivo;
- GPS com parada confirmada e velocidade 0 quando estacionado;
- música offline e biblioteca;
- radares MusicRoad com fallback direto OpenStreetMap;
- mapa offline de servidor e fallback local direto OpenStreetMap;
- cockpit responsivo usando a área real da janela.
